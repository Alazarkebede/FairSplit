⚡ What is FairSplit?
FairSplit helps households sharing a single EEU electricity meter split the monthly bill fairly and accurately — based on each home's actual kWh consumption, not a flat split.
📋 How It Works
1
Enter the Total Bill
Type the full EEU bill amount for the billing month.
2
Add Each Home
Add every sub-meter with its previous and current kWh readings.
3
Calculate Fair Split
Tap the button — each home pays exactly for what they consumed.
4
Copy & Share
Copy the results and send via WhatsApp or Telegram in one tap.
✨ Key Features
🏠 Up to 10 homes
📋 One-tap copy
📶 Works offline
🔒 Lock readings
🌙 Dark & light mode
💾 Auto-saves state
